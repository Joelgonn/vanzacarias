## 2. UX Implementada

### Estado Inicial

```
┌─────────────────────────────────────────────┐
│  Teste de Voz                               │
│  Português Brasileiro (emerald)            │
│  Toque em FALAR e diga uma frase.          │
│                                             │
│  [ 🎙️ FALAR ]  (emerald, grande, central)  │
│                                             │
│  Fonte: MICROFONE REAL — getUserMedia → ... │
│  Status: Pronto para gravar                │
└─────────────────────────────────────────────┘
```

### Estado Gravando (após FALAR)

```
  Gravando... — Fale normalmente. (rose, pulse)
  [ ⏹ PARAR ] (rose)
```

`handleFalar` garante: `getUserMedia` se necessário → `runLoadEngine` se `!isEngineReady` → `AudioContext({sampleRate: trackRate})` → `resume()` se `suspended` → `createMediaStreamSource` → `ScriptProcessor 4096` → `chunks` → `simpleCaptureRef`.

### Estado Após PARAR (automático)

```
  Processando áudio... (amber, spinner)
    → stop: capturing false, disconnect, close, combined Float32 → resample 48k→16k → micPcmRef → pcmInfo
  Transcrevendo... (stone)
    → engine.transcribe(micPcmRef.pcm, 16000) → Vosk
```

`handleParar` executa **sem intervenção do usuário**: `processando` → `transcrevendo` → `resultado`/`erro`. Nenhum botão técnico intermediário.

### Resultado

```
  Transcrição
  "Olá, quero testar o reconhecimento de voz em português brasileiro."
  [ 🎙️ FALAR NOVAMENTE ]
```

### Erros

- Sem áudio capturado (`totalLen 0`): `Não foi possível capturar sua voz. Tente novamente.`
- Sem PCM de microfone (`!micPcmRef`): mesmo
- Erro Vosk / engine: `Não foi possível transcrever o áudio. Tente novamente.`
- Sem stack trace na interface normal. Logs `[VOICE_DEBUG]` continuam para diagnóstico interno (console).

### Fixture WAV — Secundário

```
<details>
  <summary>Teste Fixture (desenvolvimento) — clique para expandir</summary>
  Fonte de áudio — Fixture: /moonshire.wav (GET local)
  [Carregar fixture] + ENGINE TEST com:
    G — MICROFONE REAL (verde, NUNCA fetch WAV)
    G — FIXTURE WAV (preto, fetch /moonshire.wav → PCM)
</details>
```

Usuário abre `/dev/voice-test` e **imediatamente entende**: botão principal testa **MICROFONE REAL**. Fixture não participa do fluxo principal, nunca carregado automaticamente, visualmente discreto.

### Regra Crítica Respeitada

Botão principal `FALAR` executa **exclusivamente**:

```
getUserMedia()
→ MediaStream (streamRef)
→ AudioContext (simpleCaptureRef)
→ PCM (micPcmRef)
→ transcrição MICROFONE (runTranscribeMic logic, sem loadFixture)
```

**Proibido e não presente:** `loadFixture()`, `fixtureRef`, `fetch('/moonshire.wav')`, arquivo WAV, upload. Se `micPcmRef` ausente, `handleParar` falha com `Não foi possível capturar...` — **nunca** substitui por fixture.
