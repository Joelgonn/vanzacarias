## 9. Limitações / Próximos passos

* Chat E2E com `Gemini` real requer sessão Supabase validada via `document.cookie` (não apenas `localStorage`); `createBrowserClient` usa cookies `sb-...`. Login via `fetch` + `localStorage` bounced to `/login`. Para validação completa, usar fluxo de login UI ou `supabase.auth.setSession` via `createClient` import. Não bloqueia KO-001.0 pois `noteResponse` é desacoplado de auth.
* Offline puro sem rede ainda requer `https://localhost` local assets; atual usa GitHub raw (rede). Próxima sprint pode restaurar `https://localhost/assets` com `server.url` handling.
